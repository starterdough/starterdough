## What Starterdough is

Starterdough is a Bun-native SaaS starter — the Svelte/Bun answer to next-forge, Makerkit and
ShipFast. Authentication, an admin surface and internationalisation are built once and served as a
website, a mobile site or installable PWA, a desktop app, a mobile app, or self-hosted on your own
server.

It has one architectural rule: **a single source of truth over HTTP.** Every surface — the SvelteKit
app, the Tauri desktop and mobile shells, the Astro sites and scripts — is a
thin client of one API (Hono + oRPC on Bun) with the same auth, the same procedures and the same
OpenAPI document. Only the API talks to Postgres.
